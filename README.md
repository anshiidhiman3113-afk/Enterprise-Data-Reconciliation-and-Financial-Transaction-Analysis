
# Enterprise Data Reconciliation and Financial Transaction Analysis

## Overview

This project was completed as part of the **iStudio Data Analytics Internship**. The objective is to reconcile enterprise transaction data collected from multiple sources by extracting information from unstructured server logs, integrating exchange rate data, and joining customer records stored in a relational database. The project demonstrates practical data engineering, SQL, data cleaning, and data analytics skills used in real-world enterprise environments.

---

## Problem Statement

Enterprise organizations often receive transaction data from multiple systems in different formats. The data may contain:

- Unstructured server logs
- Corrupted records
- Missing exchange rates
- Historical customer information
- Currency inconsistencies

The objective of this project is to clean, transform, reconcile, and integrate these datasets into a single reliable dataset for business analysis.
