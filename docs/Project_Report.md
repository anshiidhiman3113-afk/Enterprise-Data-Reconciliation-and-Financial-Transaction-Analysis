# Enterprise Data Reconciliation and Financial Transaction Analysis

## Abstract

This project focuses on enterprise-level data reconciliation by integrating multiple heterogeneous data sources into a unified analytical dataset. The workflow involves extracting transactional information from unstructured server logs, processing historical exchange rates, retrieving the latest customer information from a relational database, and producing analytical insights through data visualization.

---

# Introduction

Enterprise organizations often store data across multiple systems, resulting in inconsistencies and duplication. This project demonstrates how data engineering techniques can be applied to clean, reconcile, and analyze enterprise transaction data.

---

# Problem Statement

The project aims to solve four major challenges:

- Extracting structured information from unstructured logs.
- Handling missing exchange-rate values.
- Reconciling historical customer records.
- Producing an analytics-ready dataset.
